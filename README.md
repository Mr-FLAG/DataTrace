# DataTrace
This is the repository for all the data traces collected from public resource, including Alibaba, Facebook and Google.

Raw trace resource:

Alibaba: https://github.com/alibaba/clusterdata

Google: https://github.com/google/cluster-data

Facebook: lost

Preprocessed for distribute job execution case.

Information consists of the job ID, arrival time, number of task, data partition size (same for tasks of the same job), site distribution (sites = 10), duration of each task.
